# Maestro Frontend App

This is the Expo/React Native app subdirectory for the Maestro project.

To see the complete documentation, setup instructions, and architecture breakdown, please refer to the main repository [README.md](../README.md).

## Quick Start Commands

```bash
# Navigate to this directory
cd maestro-app

# Install dependencies
npm install

# Start the dev server
npm run start

# Launch on web (recommended for Web Audio synthesizer)
npm run web
```
